# 🎨 Aura: Algorithmic Art Engine by Fatehin Alam

**Aura** is a generative art tool built with the HTML5 Canvas API. It simulates a physics-based particle system where nodes interact, connect, and evolve over time to create unique, downloadable digital tapestries.

This project demonstrates proficiency in **Creative Coding**, **Mathematical Animation logic**, and **Canvas Optimization**.

![Tech](https://img.shields.io/badge/Engine-HTML5_Canvas-orange)
![Creator](https://img.shields.io/badge/Creator-Fatehin_Alam-blue)

## 🌟 Key Features

* **Generative Network:** Particles form constellations dynamically based on proximity algorithms.
* **Interactive Physics:** The system reacts to mouse input, creating a "repulsion field" that allows users to sculpt the art.
* **Export Capability:** Users can save their unique generated patterns as high-resolution PNGs.
* **Dynamic UI:** Glassmorphism control panel to adjust simulation speed and connection density in real-time.

1.  Clone the repository:
    ```bash
    git clone [https://github.com/Fatehin03/aura-engine.git](https://github.com/Fatehin03/aura-engine.git)
    ```
2.  Open `index.html`.
3.  Move your mouse to disrupt the particles, or adjust the sliders to change the physics.
